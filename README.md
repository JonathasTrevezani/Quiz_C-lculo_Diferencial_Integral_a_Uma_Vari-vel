## 📖 Sobre o Projeto

Este é um **quiz interativo** desenvolvido para auxiliar no estudo da disciplina **Cálculo Diferencial e Integral a Uma Variável**. O projeto foi criado com base no material de estudo da **Uninter**, oferecendo uma ferramenta prática para autoavaliação e revisão dos conceitos fundamentais de limites, derivadas, otimização, integrais indefinidas e definidas, cálculo de áreas e volumes de revolução.

## 🎯 Finalidade

* **Uso Acadêmico:** complemento aos estudos da disciplina, permitindo que alunos testem seus conhecimentos de forma interativa.
* **Uso Pessoal:** ferramenta para revisão de conteúdos antes de provas e avaliações.
* **Recurso Didático:** material de apoio para professores e tutores da disciplina.

* ✅ Questões discursivas para aprofundamento teórico

## 🚀 Como Usar

### Acesse Online

O quiz está disponível através do GitHub Pages:

🔗 **[Clique aqui para acessar o quiz](https://jonathastrevezani.github.io/Quiz_C-lculo_Diferencial_Integral_a_Uma_Vari-vel/)**

### Executar Localmente

1. Clone o repositório:

```bash
git clone https://github.com/JonathasTrevezani/Quiz_C-lculo_Diferencial_Integral_a_Uma_Vari-vel.git
```

2. Entre na pasta do projeto:

```bash
cd Quiz_C-lculo_Diferencial_Integral_a_Uma_Vari-vel
```

3. Abra o arquivo `index.html` em seu navegador.

## 📊 Sistema de Pontuação

* Cada questão vale aproximadamente **6,7 pontos**.
* São **15 questões**, totalizando **100,5 pontos**.
* O resultado é calculado automaticamente ao final do quiz.

## 🔧 Personalização

Para adicionar ou modificar questões, edite o array `questions` no arquivo `script.js`:

```javascript
{
  text: "Enunciado da questão",
  alternatives: [
    "Alternativa A",
    "Alternativa B",
    "Alternativa C",
    "Alternativa D"
  ],
  correct: "B",
  explanation: "Resolução detalhada da questão..."
}
```
